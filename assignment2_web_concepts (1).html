Assignment 2: Web Concepts

1. Internet vs WWW

Internet: It is a global network of hardware and infrastructure. It is like the roads of a city.

WWW: It stands for World Wide Web. It is the information that travels on the internet. It is like the cars on the road.

2. Generations of the Web

Web 1.0: Static web. Only reading content (e.g., simple text pages).

Web 2.0: Social web. Highly interactive (e.g., Facebook, YouTube).

Web 3.0: Semantic web. Intelligent systems (e.g., AI and smart data).

Web 4.0: Symbiotic web. Human-machine interaction (e.g., voice assistants).
